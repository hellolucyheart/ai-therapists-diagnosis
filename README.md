🟢 One deadpan line from an AI therapist: a calm clinical diagnosis that turns a human habit into a finding — and saves the punchline for the last four words.

> Diagnosis: low-grade main-character syndrome — your childhood trauma has run in the background since 2009, and you keep calling it a personality.

## Run it

```sh
python3 main.py
```

It validates the line (one sentence, 1–200 characters, opens as a diagnosis) and writes it to `/output/entry.txt`.
